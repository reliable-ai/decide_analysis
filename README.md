# Pinpointing Pivot Points: The DECIDE Framework for Data Analysis Decision Importances

This repository contains the implementation of the *DECIDE* decision importance metrics, the multiverse case studies and the analyses for the preprint.

This work is currently a work in progress and the repository and paper will continue to evolve.

## Organization

The repository is organized as follows:

- **Case Studies** (`case_studies/`): The multiverse analyses used as case studies in the paper (`fertility`, `hurricane` and `orben2019`), each one re-implementing a published multiverse analysis from the literature or describing how to process the published data.
- **R Analysis** (`analysis/`): Contains the analyses of the multiverse results generated by the case studies, incl. the computation of decision importances and the generation of plots and tables.
- **Python Analysis** (`src/`): Contains the Python implementation of the decision importance metrics (`src/metrics/`) as well as notebooks with simulations and toy examples (`src/simulations/`).

## Setup

Case studies are run using Python version 3.10, using [uv](https://github.com/astral-sh/uv) to manage the virtual environment. Please first install `uv` (see the [official installation instructions](https://docs.astral.sh/uv/getting-started/installation/)) and then run the following command to create a virtual environment with the dependencies installed.

```bash
uv sync
```

## Case Studies

The two full case studies are implemented via the [multiversum](https://simson.io/multiversum/) package. One case study (Orben et al., 2019) uses the cached results from the original analysis.

Full case studies can be run via the following commands:

```bash
# Move into the case study's directory
cd case_studies/fertility

# Run the full multiverse analysis
uv run multiversum
```

Results are written to the `output/` directory of the case study.

## R Analysis

The analysis of the multiverse results generated by the case studies.

### Setup

The analysis of the multiverse results and generation of plots is done in R. To re-run analyses, you will first need to install R.

All required packages are loaded in `analysis/R/_load.R`. Most of them can be installed from CRAN, the `nicknames` package can be installed from GitHub via `pak::pak("jansim/nicknames")`.

Notebooks can be run via the Quarto CLI with the following commands:

```bash
# Move into the analysis directory
cd analysis

# Render all analysis notebooks
quarto render .

# Render a specific analysis notebook
quarto render fertility.qmd
```

## Python Analysis

The Python implementation of the decision importance metrics, incl. *DECIDE*, as well as simulations and toy examples used in the paper.

- `src/metrics/metrics.py`: Implementation of the *DECIDE* metric and a naive tree-based importance measure.
- `src/metrics/functional_anova.py`: Functional ANOVA (fANOVA) based decision importances, used as a comparison method.
- `src/simulations/`: Jupyter notebooks with simulations and toy examples.
