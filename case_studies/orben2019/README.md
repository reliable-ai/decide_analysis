# Orben (2019) Case Study

Code: https://github.com/OrbenAmy/NHB_2019
Data / OSF Project: https://osf.io/phf8v/overview

## Steps

1. Clone the repository from GitHub
2. Download the data under `../Analysis Code/Analysis Files` from [OSF](https://osf.io/phf8v/overview) and place it in the root of the cloned repository. These should be multiple `.rda` files.
3. Copy `8_create_multiverse_dfs.R` from this repository into the root of the cloned repository.
4. Run `8_create_multiverse_dfs.R` to export the multiverse data frames.
